📦 ParcelPilot

Fictional parcel-tracking SaaS — the demo storefront for the DocPilot chatbot.

Try the chat widget (bottom-right corner). Ask it things like “How long do refunds take?”, “What is the express delivery cutoff?”, “And what about shipping to Vancouver?” — then ask something out of scope like “Do you offer pet insurance?” to see the guardrail escalate to a ticket.

Embed this chatbot on your own site

Two lines of code — no build step, no dependencies:

<script src="http://localhost:8080/widget/widget.js"
        data-api-url="http://localhost:8080"
        data-title="ParcelPilot Support"></script>

The widget reads data-api-url / data-title from its own script tag (or window.DocPilotConfig). Point data-api-url at wherever the DocPilot API runs.
