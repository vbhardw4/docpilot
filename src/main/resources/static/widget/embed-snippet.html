DocPilot embed snippet

Paste these two lines before </body> on any page. No build step, no dependencies.

<script src="https://YOUR-DOCPILOT-HOST/widget/widget.js"
        data-api-url="https://YOUR-DOCPILOT-HOST"
        data-title="Acme Support"></script>

Optional configuration (set before the script tag):

<script>
  window.DocPilotConfig = {
    apiUrl: "https://YOUR-DOCPILOT-HOST",
    title: "Acme Support"
  };
</script>
